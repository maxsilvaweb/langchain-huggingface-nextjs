# Python Backend Service

This service provides a Python-based implementation of the chat logic using FastAPI, LangChain, and Hugging Face, integrating with the existing Convex database.

## Setup

1. Create a virtual environment:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```
2. Install dependencies:
   ```bash
   pip install fastapi uvicorn langchain langchain-huggingface convex pydantic python-dotenv
   ```
